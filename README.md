# Приложение мониторинга самолётов

## Описание: 
Программа, которая собирает данные о самолётах в воздушных пространствах выбранных 
стран и сохраняет результат в JSON-файл. Взаимодействует через терминал.

## Содержание: 
Программа содержит:
- Выбор страны воздушного пространства
- Выбор страны регистрации воздушного судна
- Топ самолётов по высоте полёта

В приложении определены классы Самолётов и API-адаптера для запросов. Классы определяются 
через абстрактные базовый класс и их методы (наследование).

Приложение позволяет производить запросы по координатам стран; устанавливать и получать 
координаты стран через api-запросы; получать список самолётов; 
получать детальные характеристики по скорости и высоте полёта; 
получать данные о регистрации воздушного судна и его позывном;

В приложение введены обработчики ошибок для по скорости и высоте (не могут быть ниже 0)

### Все запросы устанавливаются по:

[openstreetmap](https://nominatim.openstreetmap.org/ui/search.html)

[opensky-network](https://opensky-network.org/)
